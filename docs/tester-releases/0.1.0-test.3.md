# Nepal Football Simulation — 0.1.0-test.3

Release date: 2026-08-30

## Highlights

- New Career exposes active A, B, and C Division clubs with division filters and club context.
- B/C starts seed playable squads before the manager career opens.
- New-save Nepal wages are division-aware; staff salary expectations are reduced to sensible simulation-only bands.
- Oversized new-save squads are deterministically reconciled through canonical free-agent release, without deleting player records.
- Player profiles explicitly label monthly salary.
- Manager and Owner/Chairman career starts are distinct; game election candidacy is earned and uses the existing deterministic election pipeline.

## Validation

- Shared-types, simulation, and desktop typechecks pass.
- Career pyramid/free-agent, manager gameplay, role switching, Chairman, Federation, and staff regressions pass.
- Election outcomes remain non-guaranteed; no public release or signing/notarization is implied.
