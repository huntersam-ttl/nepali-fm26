# Nepal Football Simulation — 0.1.0-test.6

Release date: 2026-08-31

## Visible changes

- Continue stops on the manager's unresolved matchday; the match must be handled before time can move on.
- Future fixtures are read-only and cannot be started or Quick Simmed through the backend.
- Fixtures show a clear Matchday action and simulated home-ground fallback names where no researched venue exists.
- C-Division bootstrap squads now receive adult simulation-only players (19–29) with balanced positional coverage.
- Player profiles use transparent simulation-only fallbacks for nationality, height, and preferred foot when factual data is absent.
- Tactical warnings show player names instead of raw identifiers; pitch slots, role selection, player replacement, bench management, and instruction controls remain interactive.
- Staff search/filtering is available across staff, vacancies, and candidates; hiring and responsibility reassignment remain wired to the existing market commands.
