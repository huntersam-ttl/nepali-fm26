# Nepal Football Simulation — 0.1.0-test.2

Release date: 2026-08-30

## Build

- macOS tester build, universal x86_64/arm64 app; application version `0.1.0`
- Unsigned and not notarized; right-click → Open may be required
- Distribution: `Nepal-Football-Simulation-0.1.0-macos-x64-test.zip`

## Highlights

- Chairman / Owner dashboard with ownership, club balance, budgets, transactions, sponsorships, infrastructure, and manager context
- Federation President dashboard with tenure, balance, budgets, transactions, proposals, programmes, and national teams
- Deterministic role switching and save/reload persistence
- Player contract offers, staff hiring UI, tactics persistence, grouped navigation, and clearer role errors

## Known limitations

Role dashboards expose existing read models only; unsupported takeover, election, and broad programme mechanics remain out of scope. Long-save performance is still deferred. Packaged UI click automation remains unavailable on the developer host because macOS Accessibility permissions are blocked; runtime-backed smoke is used instead.
