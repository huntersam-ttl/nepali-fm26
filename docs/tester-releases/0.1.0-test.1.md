## First session (15–30 minutes)

Launch, create a game, inspect Dashboard, Squad, two or three player pages, Fixtures, and Competition. Quick Sim one fixture, inspect the result and Inbox, save/close, then reopen and Continue. Note anything confusing or broken.

## Feedback

Use `docs/TESTER_FEEDBACK_TEMPLATE.md`. Classify each report as BLOCKER, BUG, UX, BALANCE, or FEATURE_REQUEST, and include severity P0–P3. Send the completed template with screenshots/video and the save file when relevant.

## Known limitations

Long-save performance is still being optimized. Chairman, Federation, and dedicated finance surfaces are deferred. The developer host cannot automate the packaged UI because Accessibility permissions are unavailable; runtime-backed package acceptance passed. Do not spend first-session time on 20/50-year saves, exhaustive balance, or factual-database auditing.

## Daily loop

Review and deduplicate reports each morning; prioritize P0, P1, then repeated UX issues. Reproduce, make the smallest fix, run focused regression, and publish `0.1.0-test.2`, `.test.3`, and so on as needed.
