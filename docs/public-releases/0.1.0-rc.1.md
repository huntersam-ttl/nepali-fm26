# Nepal Football Simulation 0.1.0-rc.1

Public packaging candidate for macOS. This is an external tester release, not a production promise.

## Included

- Nepal-first playable football simulation with manager, owner, chairman, and federation-president career roles.
- Bundled Node runtime and the canonical Nepal world dataset dated `2026-08`.
- DMG and ZIP artifacts in `releases/public/0.1.0-rc.1/` with SHA-256 checksums in `SHA256SUMS`.

## Current release limitations

- This candidate is unsigned and not notarized. macOS may refuse first launch or require an explicit tester override. Do not treat the package as safe for general public distribution until Developer ID signing and notarization succeed.
- The app executable is x86_64-only; the embedded Node sidecar is universal. This is not a universal app and should be tested on Intel Macs or Apple Silicon through Rosetta.
- There is no configured in-app updater or signed update manifest. Updates are manual downloads.
- The DMG is a plain install image; drag the app to Applications, then launch it from there.

## Saves, logs, and support

Saves are stored under `~/Library/Application Support/NepalFootballSim/saves`. Keep a copy of save files before testing a new build. For support, report the candidate version, macOS version, Mac architecture, reproduction steps, and relevant logs; do not include private save data unless requested. The runtime is local-only and uses a loopback port internally.
