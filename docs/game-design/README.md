# Game Design Notes

This folder holds cross-cutting design records for the manager, club
owner/chairman, and federation chairman/president modes.

## Permanent cross-cutting tracks

- [3D Presentation & Animation System](./3D_PRESENTATION_AND_ANIMATION.md) —
  state-driven 3D environments, animation and transitions across the whole
  game. **Football matches themselves are never rendered in 2D or 3D:** they
  remain Quick Sim, Key Events and Text Live on the canonical match engine.
  Every future feature sprint should include "3D presentation integration
  where meaningful".
